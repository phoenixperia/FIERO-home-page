# FIERO HP 仕様書

## ブランド戦略

### コアメッセージ
**見られ方が変われば、人生が動き出す。**

### ブランド哲学
**装いは、未来から逆算する。**

オーダースーツとは、サイズを採るものではない。なりたい姿を伺い、その姿が着ている一着を、いま仕立てる。

### ペルソナ

主軸:
- 経営者・ビジネスパーソン(30代〜50代)
- M&A後の管理職・事業部長候補・役員候補
- 紹介経由で来店する、上質志向の層

欲求の階層:
- 層1: 見られたい・舐められたくない
- 層5: 大事な場面で勝ちに行きたい

(層2〜4の本質的な変化は、対話の中で気づいてもらう設計)

### 差別化の核

- コーチング起点 — 「なりたい姿」を対話から引き出す
- 未来から逆算 — 5年後の自分が着ているスーツを、いま仕立てる
- 町田の小さな一室 — 親密な関係性、紹介中心ビジネス
- 8年の実績 — 経営者・ビジネスパーソンの装いと在り方を翻訳してきた
- Bespoke Card — 5年後のあなたを覚えているテーラー
- 装いをトータル設計 — スーツ・シューズ・レザー小物まで

## セクション別仕様

### 1. Hero

**役割**: 3秒で核を伝え、5秒で行動させる

**構成要素**:
- 上部: ブランド表記「FIERO — bespoke tailor, machida」(英字小)
- メイン: H1の3行コピー
- サブ: 3行のサブコピー
- 下部: 主CTA + 副CTA

**ビジュアル**:
- 背景: 仕立て中の手元のクローズアップ画像のプレースホルダー(SVGで雰囲気を作る)
- 配置: 左寄せ、右側に余白
- オーバーレイ: 暗めのオーバーレイ + ビネット効果

**設計意図**:
- 3行のH1は色で階層化(白→ベージュ→ゴールド)
- 視線が自然に最後の「解決行」に着地する
- サブコピーで町田・経営者層・8年・投資哲学を一段落で全て回収

### 2. Owner Story

**役割**: TAKAMASAさん個人の物語で、哲学に説得力を与える

**構成要素**:
- 哲学宣言タイトル: 「装いは、未来から逆算する。」
- 体験談本文(35歳でM&A → 5年後の自分のスーツを先に仕立てた → 1年後に事業部長へ)
- 結びの問いかけ + ストーリーの締め

**設計意図**:
- 数字(35歳/5年後/1年後/事業部長)で実話の信頼性を担保
- 「投資」キーワードでヒーローのサブコピーと連動
- 結びの「その姿から、一着をお仕立てします。」がヒーローH1の3行目と韻を踏む

### 3. Order Items

**役割**: 「何が頼めるか」を明示し、検討材料を提供

**構成要素**:
- セクション冒頭: 「装いを、足元から指先まで設計する」
- カテゴリー別アイテム一覧(5カテゴリー):
  - Suits & Jackets
  - Shirts
  - Coats
  - Shoes (Patine)
  - Leather Goods (Patine)
  - Available Items(仕入れ品)

**価格表記ルール**:
- 下限価格を強調(太く・大きく)
- 上限はカッコ書きで控えめに
- 「〜程度」表記で生地による変動を示唆

**設計意図**:
- 英字カテゴリー名で品格を出す
- パティーヌをキーワードとして強調(独自技法であることが伝わる)
- 仕入れ品は最後に控えめに置く

### 4. Process

**役割**: 予約直前の不安を解消し、行動を促す

**構成要素**:
- 冒頭リード: 「お仕立ては、対話から始まります。」
- 「いつでも引き返せる」注釈(冒頭で明示)
- 8ステップ(各ステップに番号 + タイトル + 本文)

**8ステップの構成**:
01. お問い合わせ・ご予約
02. 個別相談(1.5〜2時間)
03. 生地のご選定
04. 仕様のご選定・お見積り
05. お支払い・採寸
06. お仕立て(約1〜1.5ヶ月)
07. お渡し・最終フィッティング
08. アフターケア

**設計意図**:
- 「対話」という言葉を3回反復
- 「目指す姿」「未来」を2回反復
- 心理的階段が美しい(無料→対話→プロ採寸→楽しい選定→待つ価値→クライマックス→続く関係)
- お客様に主導権を渡す表現を全ステップに散らす

### 5. Pricing & Payment

**役割**: 価格・お支払いを誠実に開示する

**構成要素**:
- ご予算の目安(Japanese Fabric / Imported Fabric)
- Bespoke Card 作成費の説明
- お支払い方法

**設計意図**:
- ¥80,000〜の下限価格でハードルを下げる
- Bespoke Card作成費をカルテという成果物に紐付けて、手数料感を消す
- PayPal事前申告制度で透明性を出す

### 6. Customer Voice

**役割**: 第三者の証言で哲学を裏付ける

**構成要素(3層構造)**:
1. 主軸事例: M様(着用3週間後の3つの変化)
2. シューズ3名(R.T / O.H / H.A様)
3. クロージング + CTA

**設計意図**:
- M様の「見られ方が変わってきた」がヒーローH1と完璧に呼応
- 「3週間」という即効性を冒頭に
- 3つの変化を番号付きで提示
- 「あの人、最近なんだか違うな」のクロージングで自分事化を促す

### 7. Access

**役割**: 来店の物理的・心理的ハードルを下げる

**構成要素**:
- 住所(郵便番号 + 完全な住所)
- Google Map で開くボタン
- アクセス(町田駅 北口より徒歩4分)
- 営業時間 + 完全予約制
- ご連絡先(TEL + MAIL)
- セクション末尾のCTA

**設計意図**:
- 「完全予約制」で特別感を演出
- BIZcomfort町田と素直に書くことでヒーローのサブコピー「小さな一室」と整合

### 8. Contact Form

**役割**: 予約の最終着地点

**必須項目**(3つだけ):
- お名前
- ご連絡先(メール または お電話)
- ご希望日時(第1〜第3希望)

**任意項目(複数選択)**:
- ご相談したいシーン(8択)
- ご相談されたいアイテム(10択)

**任意記述欄**:
- 「目指したい姿」を、一言お聞かせください
- 例示6個を表示(ペルソナ層を網羅)
- 「具体的でなくて構いません」の優しい誘導文

**その他**:
- ご紹介者(任意)
- その他、お伝えになりたいこと(任意)

**副CTA**:
- LINE予約への誘導(https://line.me/R/ti/p/@538mhqlu)

**設計意図**:
- 必須項目を3つに絞ることで離脱率を最小化
- 「目指したい姿」記述欄で、フォーム入力中から対話を始める
- 例示でペルソナ感を伝え、自分事化を促す

### 9. Footer

**構成要素**:
- FIEROロゴ
- 哲学宣言: 「装いは、未来から逆算する。」
- 店舗情報(住所・地図ボタン)
- 営業時間・連絡先
- メニュー再掲
- 肩書き: 「ファッションプロデューサー 藤井 孝昌 / Takamasa Fujii」
- 個別相談CTA(最後の押し)
- コピーライト

## ブランド全体の言葉の反復構造

HP内で意図的に反復されるキーワード(記憶定着のため):

| キーワード | 出現箇所 |
|---|---|
| 見られ方 | H1、サブコピー、お客様の声、フォーム例示 |
| 投資 | サブコピー、オーナーストーリー、Bespoke Card 文脈 |
| 目指す姿 / なりたい姿 | H1、サブコピー、ストーリー、ご注文の流れ、フォーム |
| 対話 | サブコピー、ご注文の流れ、フォーム |
| 未来から逆算 | オーナーストーリー、Bespoke Card、フッター |

これらのキーワードは、HP実装時に**意図的に同じ言葉のまま**反復させること。同義語に置き換えないこと。

## 実装フェーズ

### Phase 1: HTMLモックアップ ← いま
- `index.html` 1ファイルにまとめる
- インラインCSS、最小限のJS
- 写真はSVGプレースホルダーで雰囲気を出す
- スマホ・タブレット・PCで崩れないこと

### Phase 2: 実装スタック決定
- Astro / Next.js / 静的HTMLのいずれかを選ぶ
- フォーム送信先の決定(Formspree / Netlify Forms / 独自API)

### Phase 3: 本番実装
- ドメイン取得
- 予約管理ツール連携
- アナリティクス導入
- 既存お客様への新HP案内
