# Claude Code 実装プロンプト

## 役割

あなたは、上質なブランドサイトを制作する熟練のフロントエンドエンジニア兼デザイナーです。
このプロジェクトでは、町田のオーダースーツ「FIERO」のホームページを、HTMLモックアップとして実装してもらいます。

## 最初にやること

1. このフォルダ内の以下のファイルを順番に読んでください:
   - `README.md` (プロジェクト概要)
   - `DESIGN_TOKENS.md` (デザイン規約)
   - `SPEC.md` (HP仕様の全文)
   - `CONTENT.md` (コピー本文)

2. 全体像を把握したら、以下の指示に従って実装してください。

---

## 今回のタスク

**シングルファイルの`index.html`** を作成してください。
すべてのCSSは`<style>`タグ内にインラインで含め、外部依存を最小限にしてください(Webフォントの読み込みのみ可)。

## 実装する全セクション(出現順)

1. **Header / Navigation**
   - 左: FIEROロゴ
   - 右: メニュー(Story / Items / Process / Voice / Contact) + 予約CTAボタン
   - スクロール時にもヘッダーが追従(sticky)

2. **Hero**
   - 背景: 仕立て中の手元のクローズアップ画像のプレースホルダー(SVGで雰囲気を出す)
   - H1の3行コピー(色で階層化)
   - サブコピー
   - CTA(主・副)

3. **Owner Story**
   - 哲学宣言タイトル
   - ストーリー本文
   - 結びの問いかけ

4. **Order Items**
   - カテゴリー別にアイテム一覧(Suits & Jackets / Shirts / Coats / Shoes / Leather Goods)
   - 価格表記は下限を強調、上限は控えめに

5. **Process**
   - 8ステップ(各ステップに番号 + タイトル + 本文)
   - 縦に並ぶシンプルなレイアウト
   - 「いつでも引き返せます」の注釈を冒頭に明示

6. **Pricing & Payment**
   - ご予算の目安
   - Bespoke Card 作成費の説明
   - お支払い方法

7. **Customer Voice**
   - 主軸: M様事例(状況 + 3週間後のご報告)
   - サブ: R.T / O.H / H.A 様の声
   - クロージング + CTA

8. **Access**
   - 店舗住所・地図ボタン
   - 営業時間・連絡先
   - CTA

9. **Contact Form**
   - 予約フォーム(必須項目 + 任意項目 + 「目指したい姿」記述欄)
   - LINE予約への副CTA

10. **Footer**
    - ロゴ、住所、連絡先、メニュー、肩書き、コピーライト

## デザイン要件

- **配色**: オフホワイト/エクル基調 + シャンパンゴールドアクセント(`DESIGN_TOKENS.md`の値を厳守)
- **タイポグラフィ**: 日本語は明朝体(Noto Serif JP)、欧文はセリフ体(Cormorant Garamond)
- **レイアウト**: 中央寄せの読み物的レイアウト、最大コンテンツ幅は880px〜1080px
- **余白**: 各セクション間に十分なゆとり(80-120px程度)
- **アニメーション**: スクロール時のフェードイン程度。動きすぎないこと
- **レスポンシブ**: スマホ・タブレット・PCの3断面で破綻しないこと
- **画像**: 写真は実物がないのでSVGプレースホルダーで雰囲気を出す
  - ヒーローの背景: 縦糸・横糸の織りを抽象化したSVGなど

## 守ってほしいこと

- **コピーは`CONTENT.md`の文言を一字一句そのまま使う**(改変しない)
- **デザイントークンは`DESIGN_TOKENS.md`の値を厳守**
- **過剰な装飾は避ける**。FIEROの世界観は「静かな上品さ」
- **絵文字は一切使わない**
- **アイコン**: Heroiconsライブラリ準拠のシンプルなSVGアイコンを最小限に使用

## 参考にしてはいけないこと

- 一般的なオーダースーツ屋のサイト(画像で攻めて、CTAボタンが派手)
- ベンチャー企業のランディングページ(動きが派手で、CTAだらけ)
- 高級ブランド(モノクロ・ミニマル一辺倒)

## 参考にしてよいこと

- 既存のシューズLP(https://fluffy-vacherin-84a470.netlify.app/)の上品さ
- 海外の独立系職人ブランド(Saddleback Leather、Aimé Leon Doreなど)の物語性
- 高級ホテル・料亭の予約ページの落ち着き

## 完了の定義

- スマホでも崩れずに見られる
- ボタンクリックで該当セクションにスムーズスクロール
- 「とにかくデモとして見せられる」状態
