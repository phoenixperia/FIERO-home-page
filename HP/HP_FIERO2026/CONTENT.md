## Process

### セクションタイトル
```
Process
```

### 冒頭リード文
```
お仕立ては、対話から始まります。

あなたが目指す姿を伺うところから、お渡し後の長いお付き合いまで。
一着が完成するまでの全ステップを、ご紹介します。
```

### 注釈
```
※ステップ02〜04の間は、いつでもお持ち帰りいただけます。
最後までご納得いただいてから、お仕立てに入ります。
```

### 01. お問い合わせ・ご予約
```
まずは個別相談のご予約を。お電話・お問い合わせフォーム・ご紹介者様経由、どのルートでも構いません。

ご相談は完全無料、ご購入の義務もございません。「まずは話を聞いてみたい」だけでも、どうぞお気軽にお越しください。
```

### 02. 個別相談(1.5〜2時間)
```
町田の小さな一室にて、ゆっくりお話を伺います。

どんな場面でその一着を着るのか。どう見られたいのか。5年後、どんな自分でいたいのか。──オーダースーツは"作る前の対話"が9割です。あなたの目指す姿を、私と一緒に言葉にしていきましょう。

対話の最後に、ざっくりとしたご予算感をお伝えします。ここで「次に進みたい」と思ったときだけ、次のステップへ。その場で決められなくて構いません。
```

### 03. 生地のご選定
```
国内外の生地ブランドから、ご相談時に伺った"目指す姿"に最適な一枚をご提案します。

気に入った生地が見つかれば、その場で在庫を確認し、決定します。ここまでは、いつでも引き返していただいて構いません。「やっぱり今日は生地だけ見て帰る」も歓迎です。
```

### 04. 仕様のご選定・お見積り
```
裏地、ボタン、ステッチ、襟の角度まで。ひとつひとつの選択を、私と対話しながら決めていきます。これは、あなたの一着をあなた自身が設計する時間です。

仕様が固まったところで、最終的な価格をご提示します。この段階で、お仕立てに進むかどうか、最終のご判断をお願いします。
```

### 05. お支払い・採寸
```
ご納得いただけたら、その場でお手続きいただきます。お支払いは、PayPal・現金・お振込みからお選びください。

※PayPalご希望の場合は、お見積り前にお伝えいただけますと助かります。
※初めてご利用の方は、別途 Bespoke Card 作成費として ¥5,000 を頂戴しております。

ご入金確認後、丁寧にお採寸し、あなたのためだけに生地を発注、制作がスタートします。

※ご入金後は、お客様だけのために生地を発注し、制作に着手するため、キャンセル・ご返金はお受けできかねます。何卒ご理解ください。
```

### 06. お仕立て(約1〜1.5ヶ月)
```
採寸を元に、職人が一着を仕上げていきます。

通常スーツで約1〜1.5ヶ月、コートは約2ヶ月。少しお時間を頂戴しますが、それは"あなたの未来の一着"が形になる時間です。
```

### 07. お渡し・最終フィッティング
```
完成した一着を、あなたの体に合わせて最終調整します。

鏡の前に立った瞬間の、その一着を着た自分を、ぜひ感じてください。──「ここから、変わっていく」その瞬間に立ち会えることが、私の何よりの喜びです。
```

### 08. アフターケア
```
お渡しは、お付き合いの終わりではなく、始まりです。

体型の変化に合わせたお直し、長く着ていただくためのメンテナンス、シーズンに合わせた着こなしのご相談──。「こんなこと聞いていいのかな」と思うことこそ、お気軽にどうぞ。一着を10年お付き合いいただけるよう、伴走いたします。
```
