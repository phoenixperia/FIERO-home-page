# FIERO Website Project

ファッションプロデューサー 藤井孝昌 / FIERO のオフィシャルサイト制作プロジェクト。

## プロジェクト概要

町田のオーダースーツ・パティーヌシューズの店「FIERO」のホームページを制作する。コーチング起点・未来から逆算するという独自の哲学を体現する、上質で対話的なブランドサイト。

## ゴール

- 個別相談の予約獲得をサイトの最終ゴールとする
- 「見られ方が変われば、人生が動き出す」というブランドメッセージを体現する
- 経営者・ビジネスパーソンが「自分のことだ」と思えるサイトにする

## 進め方

1. **Phase 1: HTMLモックアップ** ← いまここ
   静的なHTML/CSSで全体の世界観を確認する
2. **Phase 2: 実装スタック決定**
   Astro / Next.js / 静的HTMLのいずれかを選ぶ
3. **Phase 3: 本番実装・デプロイ**
   ドメイン・フォーム・予約管理ツールとの連携

## ファイル構成

```
fiero-website/
├── README.md          ... このファイル(プロジェクト概要)
├── PROMPT.md          ... Claude Codeに渡す実装指示プロンプト
├── SPEC.md            ... HP仕様の全文(ヒーローからフッターまで)
├── DESIGN_TOKENS.md   ... 色・フォント・間隔・余白などのデザイントークン
└── CONTENT.md         ... 各セクションのコピー全文
```

## 各ファイルの使い方

| ファイル | 用途 |
|---|---|
| `PROMPT.md` | Claude Codeを起動した時、最初にこれを読ませる |
| `SPEC.md` | 全体仕様の参照ドキュメント。実装中の判断基準 |
| `DESIGN_TOKENS.md` | CSS変数・タイポグラフィの根拠。実装時に必ず参照 |
| `CONTENT.md` | コピペで使えるコピー文集。テキストの完全な原文 |
